# WHAT IS  AIRFLOW FERNET KEY?
# Airflow uses Fernet encryption to encrypt sensitive information stored in its metadata database,
# especially things such as connection passwords and other credentials.
# (Generate fernet key once and keep the same value in your .env, Because Airflow needs the same key to decrypt data
# that it previously encrypted. If you change the key later, Airflow may no longer be able to decrypt existing encrypted credentials.)
